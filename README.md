# loomiapp — PWA (устанавливается на iOS и Android)

## Важно: нужен HTTPS-хостинг

PWA (Service Worker, «Установить приложение», офлайн-режим) технически
не работает при открытии файла напрямую (`file://`) — браузеры требуют
безопасный контекст: `https://` или `http://localhost`. Это ограничение
самих браузеров, а не этого проекта. Поэтому после распаковки архива
нужно один раз захостить папку — это займёт 1–2 минуты.

### Самый быстрый способ — Netlify Drop (бесплатно, без регистрации)

1. Откройте **https://app.netlify.com/drop** в браузере на компьютере.
2. Перетащите папку `pwa` (со всем содержимым: `index.html`,
   `manifest.json`, `service-worker.js`, `icons/`) на страницу.
3. Через несколько секунд вы получите ссылку вида
   `https://random-name-123.netlify.app` — откройте её на телефоне.

### Альтернативы (тоже бесплатно, тоже без сборки)

- **Vercel** (vercel.com) — Import → Drag & Drop.
- **GitHub Pages** — залить папку в репозиторий, включить Pages в
  настройках репозитория.
- **Cloudflare Pages** — Direct Upload.

### Локальное тестирование в той же Wi-Fi сети (без загрузки в интернет)

```bash
cd pwa
python3 -m http.server 8000
```

Затем на компьютере откройте `http://localhost:8000` — Service Worker
и «Установить» будут работать (localhost считается безопасным
контекстом). Открыть с телефона по IP компьютера (`http://192.168.х.х:8000`)
не получится в полной мере — для установки на телефон всё равно нужен
https, поэтому для реального теста на устройстве используйте один из
вариантов хостинга выше.

## Установка на устройство

### Android (Chrome)
Откройте ссылку → сверху экрана появится баннер «Установить» (или
Chrome сам предложит через ⋮ → «Добавить на главный экран»). Дальше
приложение открывается как обычное — с иконкой на рабочем столе, без
адресной строки.

### iOS (только Safari — в Chrome/другом браузере на iOS так нельзя)
Откройте ссылку в **Safari** → нажмите **Поделиться** (значок квадрата
со стрелкой вверх, внизу экрана) → **«На экран «Домой»»** → Добавить.
Приложение появится как иконка на рабочем столе — открывается на весь
экран, без интерфейса Safari. Внутри самого приложения тоже есть
подсказка с этими же шагами (баннер снизу экрана, если вы уже в Safari
и ещё не установили).

## Что реализовано

Тот же набор функций, что и в предыдущей HTML-версии для тестирования
в чате, но:
- убран мокап телефона (рамка/чёлка) — приложение теперь заполняет
  весь реальный экран устройства, с учётом «безопасных зон» (вырез/
  индикатор жеста на iPhone) через `env(safe-area-inset-*)`;
- данные хранятся в `localStorage` — сохраняются между запусками прямо
  на устройстве, офлайн;
- `service-worker.js` кэширует оболочку приложения — открывается даже
  без интернета после первого захода;
- локальные напоминания через `Notification API` (спросит разрешение
  при первом тапе по экрану) — работают, пока приложение открыто или
  свёрнуто в фоне на Android; на iOS PWA push-уведомления в фоне не
  поддерживаются Safari (ограничение самой iOS, не этого кода) —
  напоминания сработают, если приложение открыто.

Экраны: Сегодня, Проекты + Workspace (Задачи/Заметки/Подпроекты/
Статистика), Планер (Неделя с drag-and-drop / Месяц + цветные даты),
Аналитика (тепловая карта + Колесо баланса), Inbox (обработка мыслей),
Настройки (9 тем, акцентный цвет, экспорт/импорт JSON, сброс данных).

## Структура

```
pwa/
  index.html          — само приложение
  manifest.json        — имя, иконки, цвета, display:standalone
  service-worker.js    — офлайн-кэш оболочки
  icons/
    icon-192.png
    icon-512.png
    icon-512-maskable.png   — с полями под маску Android (адаптивная иконка)
    icon-180.png            — apple-touch-icon для iOS
```

## Если что-то поменяете

После правки `index.html` увеличьте номер версии кэша в
`service-worker.js` (`CACHE_NAME = 'moy-proekt-v2'` и т.д.) — иначе
уже установленное приложение продолжит показывать закэшированную
старую версию до следующего явного обновления кэша браузером.
